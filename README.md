# Face Recognition Attendance System — Starter Project

## Open in VS Code
1. Extract this ZIP file.
2. In VS Code, select **File → Open Folder** and open `Face-Attendance-System`.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.

## Included
- Home page
- Student registration with webcam photo capture
- Attendance entry using a registered-student dropdown
- Attendance records table
- Browser `localStorage` for demo data

## Important limitation
This starter project captures and stores student photos, but it does **not yet perform actual face recognition**. The attendance page currently uses manual student selection. Facial descriptor matching, model files, secure database storage, and admin authentication are future development steps.

Camera access generally requires localhost/HTTPS and browser permission. Data is stored only in the current browser profile and can be lost if browser storage is cleared. Get consent before collecting or storing facial images.
